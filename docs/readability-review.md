# 独立可读性审查与修订

## 审查方式

按用户要求，在功能实现、单元/兼容测试、竞态检查、静态构建与真实 PTY 冒烟之后，单独委派一个只读 Oracle 子代理，从第一次接手项目的人类维护者角度审查。没有要求该代理实现代码，也没有让它继续派发其他代理。

代理报告通读了当前手写 Go、测试和工具，并对照契约、迁移与文档；未修改文件、未重跑测试。它不能通过当前工具核对 Git 删除项，因此审查范围不等同于完整 Git diff 审计。

## 原始结论摘要

> 主干可读，管理链路仍有明显的隐式约定；建议完成局部修正后通过可读性验收，不需要大规模重构。

认可点：启动与组装路径清楚，Agent 白名单与事务流程可以顺序跟读，中文注释总体扼要，多数测试描述用户行为。未额外确认需要单列的严重正确性问题。

## 已处理的必要修正

| 审查发现 | 修正 |
| --- | --- |
| 权限通过 SQL 列位置、`row[index+3]`、`flags[0]` 等约定传递 | 新增 `admin.UserPermissions` 具名投影；SQLite 读写及 TUI 回填均使用字段名；表格列仅负责展示 |
| SQL 的 `LIMIT 200` 字符串后缀暗中决定分页 | 分页 SQL 显式包含 `OFFSET ?`；概览统计使用独立查询，不再解释 SQL 排版 |
| 管理动作与日报状态散落为字符串 | 新增 `admin.Action`、`report.Status` 及具名常量；入口校验未知值；日报存储端口参数明确命名 |
| TUI 把 Context 存进模型字段 | 上下文、取消与请求收尾由程序入口拥有；模型保存命令构造能力；关闭会话后拒绝迟到请求并等待正在执行的请求结束 |

新增了真实用户投影→表单→未修改提交的往返测试、真实数据库第二页测试，以及会话取消和关闭后拒绝请求的测试。

## 已处理的局部可选建议

- 展开应用依赖组装、网络配置、投稿字段转换、权限表单及恢复页面的密集字面量。
- 爬虫栏目改为具名 `label/path` 字段。
- 健康检查测试走实际生产路由，删除只用于健康检查的另一套 `NewRouter` 入口。
- 收窄 `NoticeReader`，不再要求写入能力；复用已有 `searchInput`。
- 调度变量区分尝试时间与成功时间；读取调度进度失败明确记录日志。
- Agent 预算名称区分字符与字节；`clipRunes` 明确截断单位。
- TUI 测试按动作语义查找菜单，不依赖第几个菜单。
- 补充 API Key 重复绑定和原值不可变性的断言，使测试注释与证据一致。
- 在架构文档中明确线上事务审核与已有领域方法的实际调用关系，不为形式分层搬迁整套管理代码。

## 审查边界

以上修订由主代理实施；独立代理的原始报告不是对修订版的二次批准。修订版通过本地格式化、静态检查、测试和竞态检查后交付。可读性审查也不能替代安全审计、真实模型验收或生产压测。

## 2026-09-14 后续体验改进复核

在 systemd CLI、Bubbles/Vim、事件协议、VFS 和爬虫任务实现后，再次请求独立复核。code_reviewer 的独立服务因 429 配额限制没有执行，不计为审查证据；随后只读 Oracle 阅读重点新增及修改文件，未再委派。

确认的两项 P2 已修正：

1. 中文详情把字符数当作终端列宽传入截断函数，导致进入 viewport 前丢失尾部。现在详情只清除控制字符，显示宽度截断仅用于列表等有界摘要。

两项先新增失败测试再修正，通过专项回归。审查未要求广泛重构；明确未完成严格的 index/diff 归属审计、真实 systemd 部署和真实模型验收。本轮后续修订由主代理验证，不将原审查报告当作修订版的二次批准。
